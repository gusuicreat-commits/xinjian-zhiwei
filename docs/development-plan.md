# 芯鉴知微分阶段开发计划

## 工作原则

- 每次只实施一个 Phase，完成测试、构建和状态文档后停止。
- 修改前读取相关文件并检查 Git；不编造账号、设备、数据或密钥。
- 所有模拟数据明确标记为测试数据。
- 每个阶段以可重复命令和实际输出验收，失败必须调查原因。

## 阶段计划

当前进度：Phase 0 至 Phase 9 已完成，Phase 9.5 已完成代码实现并等待独立审计。生产对话模型已固定为 DeepSeek 官方 API 的 `deepseek-v4-flash` 非思考模式，但没有真实密钥、外发授权或正式知识，默认不发起 AI 请求，也不得声称已有专业知识或真实 AI 诊断能力。

| Phase | 目标 | 核心交付物 | 主要验收 |

## 阶段门禁

每阶段开始前记录：当前发现、计划修改/新增文件、风险和验收命令。每阶段结束记录：修改/新增文件、迁移、执行命令、测试和构建结果、已知问题、待补充信息与下一阶段目标。

在用户明确输入“继续下一阶段”前，不进入后续 Phase。
