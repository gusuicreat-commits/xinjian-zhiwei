# 芯鉴知微前端页面审核包

本包仅用于界面与交互审核，所有设备、日志、传感数据、诊断和教师处置记录均为内置合成数据，不连接后端、数据库或外部 AI 服务。

## 启动方式

### macOS

双击 `启动审核.command`。浏览器打开后即可开始审核；审核完成后关闭终端窗口。

### Windows

双击 `启动审核.bat`。如果系统找不到 `py`，可在本目录打开终端并运行：

```text
python -m http.server 8008
```

然后访问 `http://localhost:8008/#/login`。

## 四个审核页面

- 学生端登录：`http://localhost:8008/#/login`
- 学生端工作台：`http://localhost:8008/#/student`
- 教师端登录：`http://localhost:8008/#/teacher/login`
- 教师端工作台：`http://localhost:8008/#/teacher`

审核模式不校验真实凭据。登录页如需体验跳转，可在两个输入框中填写任意非空内容。

## 建议反馈维度

- 视觉层级、字体大小和信息密度是否合适；
- 桌面端与窄屏下是否存在遮挡、溢出或难以阅读；
- 登录入口、刷新、页面定位、搜索和审核动作是否容易理解；
- 学生端与教师端的品牌风格是否统一；
- 业务术语是否准确、是否需要进一步简化。
