# 芯鉴知微前端页面审核包

核对日期：2026-09-27。本说明是前端静态审核包的模板。审核构建的设备、日志、读数、诊断和教师处置展示使用内置合成数据，不能证明后端功能、真实身份权限、硬件或 AI 已通过验收。

## 从源码准备审核包

源码中的 `frontend/review-package/` 仅有本说明及启动脚本，不能直接作为完整网站启动。维护者先在 `frontend/` 中安装锁定依赖并运行：

```bash
npm ci
npm run build:review
```

将生成的 `review-dist/` 内容与本目录的说明、两个启动脚本复制到一个新的交付目录。确认该目录同时含 `index.html`、`assets/` 和启动脚本；启动脚本从自身所在目录提供文件。目前构建命令只生成 `review-dist/`，不会自动组装交付目录。不要复用旧构建冒充当前版本，随交付注明代码版本与构建日期。

## 启动方式

### macOS

在完整交付目录双击 `启动审核.command`，需要可用的 Python 3。服务器启动后刷新浏览器即可开始审核；审核完成后关闭终端窗口。脚本不能启动时，可在该目录运行 `python3 -m http.server 8008`。

### Windows

在完整交付目录双击 `启动审核.bat`，需要可用的 Python 3。如果系统找不到 `py`，可在该目录打开终端并运行：

```text
python -m http.server 8008
```

然后访问 `http://localhost:8008/#/login`。

## 四个审核页面

- 学生端登录：`http://localhost:8008/#/login`
- 学生端工作台：`http://localhost:8008/#/student`
- 教师端登录：`http://localhost:8008/#/teacher/login`
- 教师端工作台：`http://localhost:8008/#/teacher`

可直接打开工作台查看合成页面。体验学生登录跳转时，选择“测试设备演示”并填写任意非空测试内容；教师审核登录同样可使用非空测试内容，不输入真实凭据。

## 当前审核范围

审核模式提供明确的演示学生入口；教师工单认领/处理/关闭和诊断审核会改变标签页内的合成记录，刷新后保留。支持的学生反馈和保存解释也仅改变演示数据。所有API请求受离线守卫阻止，不连接真实业务。重新检查和真实会话/问题管理未模拟的操作禁用并说明原因；不能用此包验收账号准入、真实诊断或后端权限。关闭标签页会清除演示状态。
